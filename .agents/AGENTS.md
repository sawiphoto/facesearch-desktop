# กฎการทำงานของ AI Agent สำหรับโครงการค้นหาใบหน้า

## กฎเหล็กในการประมวลผลคำสั่ง
1. **ทบทวนแผนงานก่อนทำงานเสมอ:** ทุกครั้งที่ผู้ใช้สั่งการหรือมอบหมายงานย่อย AI จะต้องสรุปสิ่งที่ต้องทำโดยอ้างอิงจากแผนงานหลัก `implementation_plan.md` และส่งรายงานข้อความสรุปสั้น ๆ ให้ผู้ใช้ตรวจสอบก่อน
2. **ห้ามทำงานจนกว่าจะได้รับการอนุญาต:** AI AI ห้ามสร้างไฟล์ แก้ไขโค้ด หรือสั่งคำสั่งดำเนินการใด ๆ ลงบนระบบจนกว่าผู้ใช้จะส่งข้อความเห็นชอบในแผนหรือขั้นตอนนั้น ๆ อย่างชัดเจน (เช่น ตอบว่า "ตกลง" หรือ "ดำเนินการได้")
3. **อัปเดตเวอร์ชันบน GUI และ README.md เสมอ (/learn):** ทุกครั้งที่มีการแก้ไขโค้ด จะต้องทำการอัปเดตเลขเวอร์ชันใน `README.md` (จากบนลงล่าง) และอัปเดตเลขเวอร์ชันใหม่บนหน้าโปรแกรม GUI (แถบ Window Title และ Sidebar Logo Header) เพื่อให้ผู้ใช้เห็นทันทีที่เปิดใช้งานโปรแกรม
4. **ทดสอบเส้นทางการทำงานจริง (Execution Path Runtime Verification):** ในขั้นตอนการตรวจสอบความถูกต้อง (Verify) AI ห้ามพึ่งพาเพียงคำสั่ง `py_compile` แต่จะต้องสร้างสคริปต์จำลองทดสอบรันโค้ดจริงครอบคลุมทุกเงื่อนไข (Execution Paths / Edge Cases) ก่อนประกาศผลเสมอ เพื่อป้องกันปัญหา Runtime / Variable Scope Error
5. **ค้นหาและใช้โค้ดเดิมเสมอ (Audit & Reuse Original Code First):** ก่อนเขียนฟังก์ชันหรือเรียกใช้เมธอดใดๆ ใหม่ AI จะต้องใช้เครื่องมือ Grep/Code Search ค้นหาโครงสร้างและชื่อฟังก์ชันเดิมที่ทำงานได้ผลอยู่แล้วในไฟล์อื่นก่อนเสมอ ห้ามเดาหรือเขียนชื่อเมธอดใหม่ขึ้นมาเองโดยเด็ดขาด
6. **มาตรฐานการถอดรหัสภาพสากลและป้องกัน Silent Failure (Multi-Format Decoding Standard):** ห้ามใช้ `cv2.imdecode()` เพียงอย่างเดียวในการอ่านรูปภาพจากผู้ใช้/Google Drive ต้องมี Fallback ผ่าน `pillow-heif` และ `Pillow` เพื่อรองรับไฟล์ iPhone (`.HEIC`/`.HEIF`), `.WEBP`, `.TIFF` เสมอ และต้องแยกสถานะ "อ่านไฟล์ไม่สำเร็จ (Decode Error)" ออกจาก "สแกนแล้วไม่พบใบหน้าคนจริง (0 Faces on Valid Image)" ห้ามปล่อยให้ความล้มเหลวกลายเป็นข้อมูลปกติเด็ดขาด
7. **ห้ามด่วนสรุปข้อมูลโดยไม่ตรวจสอบเชิงลึก (Deep Data Auditing & No Generalization):** ในการวิเคราะห์หรือตอบคำถามเกี่ยวกับข้อมูลที่ผิดปกติ AI ต้องสืบค้นสถิติเชิงลึก (ตรวจสอบประเภทไฟล์, นามสกุล, ขนาด, และสุ่มตรวจสอบภาพจริงหลากหลายเงื่อนไข) ห้ามนำตัวอย่างรูปภาพเพียงรูปเดียว (เช่น รูปโล่รางวัล) มาด่วนสรุปหรือเหมารวมชุดข้อมูลทั้งหมดเด็ดขาด
8. **มาตรฐานประสิทธิภาพสูงและตอบสนองทันที ไร้การหน่วง (High Performance & Zero-Lag Standard):** ทุกครั้งที่ได้รับคำสั่งปรับปรุงหรือพัฒนาฟีเจอร์ใหม่ AI จะต้องคำนึงถึงความเร็วในการใช้งานเป็นอันดับสำคัญเสมอ (โหลดเร็ว ติดมือ ไม่ lag ไม่ค้าง) โดยต้องประยุกต์ใช้เทคนิคที่เหมาะสม เช่น In-Memory Caching สำหรับข้อมูล/รูปภาพที่ต้องเรียกดูซ้ำเพื่อลด Disk I/O เป็นศูนย์, การประมวลผลงานเครือข่าย/งานคำนวณหนักใน Background Daemon Thread เสมอเพื่อป้องกันหน้าจอ GUI ค้าง, การใช้ Debounce Timer ป้องกันการประมวลผลซ้ำซ้อนขณะพิมพ์ค้นหา, และการใช้ Batch API เพื่อให้โปรแกรมตอบสนองได้อย่างรวดเร็วและลื่นไหลที่สุด
